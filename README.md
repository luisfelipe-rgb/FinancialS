# FinancialS

App financeiro para controle de DRE e Fluxo de Caixa.

## Funcionalidades
- 📊 Visão DRE (regime de competência)
- 💰 Visão Caixa (fluxo de pagamentos)
- 📅 Filtro por mês
- 💾 Google Sheets como fonte de verdade
- 📥 Exportar Excel

## Tech Stack
- HTML + React + Tailwind
- Google Sheets API v4
